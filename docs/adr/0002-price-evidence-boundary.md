# Keep the first release focused on price evidence

The first public release will map fixed-band price-per-square-foot summaries and expose the underlying resale transactions, without amenity, commute, or desirability scoring. This deliberately prevents the product from presenting an opaque judgement of a home's overall value while retaining an extensible OneMap integration for future location context. HDB's metric source values remain stored in their original unit and are converted for presentation.
